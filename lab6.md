### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

**Ответ:**

1. `const auto Pi = acos(0) * 2;` — работает. Значение `Pi` нельзя изменить, но вычисление во время компиляции не обязательно.
2. `constexpr auto Pi = std::acos(0) * 2;` — `constexpr` требует вычислить значение при компиляции. В C++17 такой код может работать в одном компиляторе и выдавать ошибку в другом, потому что `std::acos` не обязана вычисляться на этапе компиляции.
3. `const auto Pi = acos(x) * 2;` — работает. `x` — обычная переменная, поэтому вычисление `Pi` при компиляции не гарантируется.
4. `constexpr auto Pi = std::acos(x) * 2;` — ошибка компиляции. Обычную переменную `x` нельзя использовать здесь для вычисления `constexpr`.

В первых трёх случаях, когда код запускается, выводится `3.14159`.

Для проверки достаточно по очереди менять строку с `Pi` в программе из задания и сохранять каждый вариант в отдельный `.cpp`-файл.

**Итог:** `const` означает, что значение нельзя менять. `constexpr` означает, что значение должно быть известно уже при компиляции. Из этих вариантов только второй объявляет константу этапа компиляции, если компилятор принимает такой код.

### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

**Ответ:**

Например, введём числа:

```text
3 4
1.5 2.5
```

Получим:

```text
7
4
```

В первом блоке `x` и `y` имеют тип `int` (целые числа), во втором — `double` (дробные числа).

Фигурные скобки создают отдельные области видимости. Переменные из первого блока не используются во втором, поэтому там можно снова назвать переменные `x` и `y`.

Если просто убрать внутренние скобки, программа не скомпилируется: в одной области нельзя два раза объявить переменные с такими же именами.

**Итог:** в этой программе скобки нужны. Без них можно обойтись, если во втором блоке назвать переменные иначе, например `a` и `b`.

### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

**Ответ:**

Программа выводит `18`.

Внешний цикл использует значения `i = 0, 1, 2, 3`. Внутренний цикл каждый раз прибавляет к `s` числа `0 + 1 + 2 = 3`.

После внутреннего цикла выполняется `s += i`. Здесь `i` относится к **внешнему** циклу. В C++ у двух циклов разные переменные с одинаковым именем.

Получаем по шагам:

```text
1-й проход: s = 0 + 3 + 0 = 3
2-й проход: s = 3 + 3 + 1 = 7
3-й проход: s = 7 + 3 + 2 = 12
4-й проход: s = 12 + 3 + 3 = 18
```

**Итог:** ответ `18`, потому что внутренний `i` не меняет внешний `i`.

### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

**Ответ:**

Программа выводит `20`.

Как и в C++, внутренний цикл четыре раза прибавляет сумму `0 + 1 + 2 = 3`. Но в Python оба цикла используют одну и ту же переменную `i`.

После внутреннего цикла `i` всегда равна `2`, поэтому строка `s += i` добавляет ещё `2`.

```text
1-й проход: s = 0 + 3 + 2 = 5
2-й проход: s = 5 + 3 + 2 = 10
3-й проход: s = 10 + 3 + 2 = 15
4-й проход: s = 15 + 3 + 2 = 20
```

Внешний цикл всё равно проходит четыре раза, потому что берёт следующие числа из `range(4)`.

**Разница:** в C++ внутренний `for` создаёт свою переменную `i`. В Python новый `for` не создаёт отдельную область видимости, поэтому внутренний цикл меняет тот же `i`. Поэтому C++ выводит `18`, а Python — `20`.

### Задание 5 **(2)**

*Напишите свой пример программы на* **С++**, *создающий и использующий пространства имен. Программа
должна содержать не менее двух пространств имен.*

**Ответ:**

```cpp
#include <iostream>

namespace Sum {
    int calc(int a, int b) {
        return a + b;
    }
}

namespace Product {
    int calc(int a, int b) {
        return a * b;
    }
}

int main() {
    std::cout << Sum::calc(2, 3) << std::endl;
    std::cout << Product::calc(2, 3) << std::endl;
    return 0;
}
```

Результат:

```text
5
6
```

Здесь два пространства имён: `Sum` и `Product`. В каждом есть функция `calc`, но они не мешают друг другу.

Запись `Sum::calc(2, 3)` вызывает сложение, а `Product::calc(2, 3)` — умножение. Знак `::` показывает, из какого пространства имён берётся функция.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

**Ответ:**

Исходный вариант медленный, потому что миллион раз **копирует** строки по 100000 символов. Временная строка `c` и два присваивания создают лишнюю работу.

Быстрый способ — `swap`:

```cpp
for (int i = 0; i < 1000000; i++) {
    std::swap(a, b);
}
```

`swap` меняет строки местами без копирования всех символов.

Чтобы оставить временную переменную и присваивания, можно использовать `std::move`:

```cpp
for (int i = 0; i < 1000000; i++) {
    std::string c(std::move(a));
    a = std::move(b);
    b = std::move(c);
}
```

`std::move` позволяет переместить данные строки вместо их копирования. Для обоих вариантов нужны заголовки `<string>` и `<utility>`.

При проверке с GCC 14.2 (`-O2`) получилось примерно:

- исходный код — `5.75` с;
- со `swap` — `0.0033` с;
- со `std::move` — `0.0066` с.

На другом компьютере время может отличаться. Все варианты выводят `ab`.

**Итог:** ошибка исходного кода — лишнее копирование длинных строк. `swap` и `std::move` решают эту проблему.

### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

**Ответ:**

Сначала `a` указывает на строку `'Hello world'`.

После `b = a` обе переменные указывают на **одну и ту же строку**. Поэтому `id(a)` и `id(b)` одинаковые.

После `a += ' and goodbye'` получается новая строка `'Hello world and goodbye'`. Теперь `a` указывает на неё, а `b` по-прежнему указывает на `'Hello world'`.

Пример результата (числа `id` условные):

```text
Hello world 1001
Hello world 1001
Hello world and goodbye 2002
Hello world 1001
```

`id()` возвращает номер, по которому Python различает объекты. В CPython это обычно адрес объекта в памяти.

Исходная строка может быть подготовлена ещё до выполнения этих команд. При `b = a` новая строка не создаётся. Новая строка с полным текстом появляется при добавлении `' and goodbye'`.

**Итог:** строки в Python нельзя менять на месте. Когда мы «добавляем» текст, переменная начинает указывать на другую строку.

### Задание 8 **(2)**

*Пусть* **a** - *строковая переменная в программе на* **Python**.
*Есть ли разница между работой присваивания*
```b = a```
и
```b = a[:]```
*Напишите программу для демонстрации различий.*

**Ответ:**

`b = a` даёт переменной `b` ссылку на ту же строку. `b = a[:]` берёт всю строку с помощью среза.

Для обычных строк результат одинаковый. В CPython полный срез обычно даже не создаёт новый объект.

```python
a = 'Hello world'
b = a
c = a[:]

print(a == b, a == c)
print(a is b, a is c)

a += ' and goodbye'
print(a)
print(b)
print(c)
```

Обычный результат в CPython:

```text
True True
True True
Hello world and goodbye
Hello world
Hello world
```

`==` сравнивает текст строк, а `is` проверяет, один ли это объект. В других реализациях Python результат проверки `is` для полного среза может отличаться.

**Итог:** заметной разницы в работе со строками здесь нет: после изменения `a` значения `b` и `c` останутся прежними.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

**Ответ:**

```python
for i in range(26):
    letter = chr(ord('a') + i)
    for j in range(100):
        name = letter + str(j)
        globals()[name] = i * 100 + j + 1

print(a0, a99, b0, b99, z0, z99)
```

Результат:

```text
1 100 101 200 2501 2600
```

Первый цикл перебирает 26 букв от `a` до `z`. Второй — числа от `0` до `99`.

`ord('a')` получает код буквы `a`, а `chr()` превращает код обратно в букву. Строка `letter + str(j)` собирает имена `a0`, `a1`, ..., `z99`.

`globals()[name] = ...` создаёт переменную с этим именем. Формула `i * 100 + j + 1` задаёт разные значения от `1` до `2600`.

Всего получается `26 * 100 = 2600` переменных.
