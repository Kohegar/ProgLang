### Задание 3 **(2)**
*Объясните работу фрагмента программы на С++. В ходе объяснения следует использовать таблицу кодов символов.*
```
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

**Ответ:**
1. Строка `char a = 'a';` инициализирует переменную числовым ASCII-кодом знака 'a', равным **97**.
2. Операция `a = a + 10;` увеличивает код до 107 (97 + 10). Согласно таблице ASCII, под этим номером находится символ **'k'**. На экран выводится: `k`.
3. Операция `a = a + 250;` приводит к значению 357 (107 + 250). Поскольку тип `char` ограничен диапазоном от -128 до 127, возникает **эффект переполнения**. Значение циклически пересчитывается в рамки доступного диапазона: 357 - 256 = 101. Число 101 в кодировке ASCII отвечает за символ **'e'**. На экран выводится: `e`.

### Задание 4 **(2)**

*Перепишите программу из предыдущего задания на Python, используя функции* **chr** и **ord**.
*Почему ее вывод отличается от вывода программы на С++?*

**Ответ:**
Реализация алгоритма на Python:
```python
char_var = 'a'
char_var = chr(ord(char_var) + 10)
print(char_var, end='')
char_var = chr(ord(char_var) + 250)
print(char_var, end='')
```
**Анализ различий в выводе:**
В языке C++ переменная типа `char` занимает строго 1 байт памяти, из-за чего сложение вызывает арифметическое переполнение (счет идет по модулю 256). В Python числовые значения и строки обладают **динамической точностью**, исключающей аппаратное переполнение. Инструкция `chr(357)` корректно сопоставляет числу символ из таблицы Юникода (**'団'**), не зацикливая вычисления вокруг начальных ASCII-символов.

### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* x+x-x=x, *но при этом*
(x*2)/2!=x? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```

**Ответ:**
Диапазон значений для типа `unsigned short` составляет от 0 до 65535 (всего 2^16 вариантов). Любой выход за эти границы приводит к вычислению остатка от деления на 65536.
1. **Расчет значения y:** Выражение `x + x` дает 40000 + 40000 = 80000. Из-за переполнения получаем: 80000 - 65536 = 14464. Далее при `y - x` вычисляется 14464 - 40000 = -25536. Приведение отрицательного результата к беззнаковому типу восстанавливает значение: -25536 + 65536 = 40000. В данном уравнении переполнение полностью нивелировалось последующим вычитанием, поэтому **y = 40000**.
2. **Расчет значения z:** Операция `x * 2` также дает 80000, что с учетом переполнения записывает в `z` число **14464**. Последующее деление `z / 2` дает результат 14464 / 2 = 7232. Старший бит, утерянный при переполнении, невозможно восстановить делением, из-за чего **z = 7232** (что отличается от исходных 40000).

### Задание 6 **(2)**

В отчете надо привести вычисления, приводящие к ответу.*
```
std::cout << 2000000000 + 1000000000 << std::endl;
std::cout << 2000000000U + 1000000000U << std::endl;
std::cout << 2500000000U + 2500000000U << std::endl;
std::cout << 2500000000LL + 2500000000LL << std::endl;
std::cout << 20000U * 200000U << std::endl;
std::cout << 200000U * 200000U << std::endl;
```

**Ответ:**
1. `2000000000 + 1000000000`: Используется стандартный знаковый тип `int` (лимит 2 147 483 647). Итоговое значение 3 000 000 000 провоцирует знаковое переполнение. Расчет: 3000000000 - 4294967296 = **-1294967296**.
2. `2000000000U + 1000000000U`: Литералы имеют тип `unsigned int` (лимит 4 294 967 295). Результат 3 000 000 000 входит в доступные границы. Ответ: **3000000000**.
3. `2500000000U + 2500000000U`: Тип `unsigned int`. Суммарное значение 5 000 000 000 превосходит разрядную сетку. Расчет: 5000000000 - 4294967296 = **705032704**.
4. `2500000000LL + 2500000000LL`: Суффикс задает тип `long long` (64 бита с очень широким диапазоном). Сумма 5 000 000 000 сохраняется без искажений. Ответ: **5000000000**.
5. `20000U * 200000U`: Переменные типа `unsigned int`. Результат умножения составляет 4 000 000 000, что строго меньше максимального предела беззнакового int. Ответ: **4000000000**.
6. `200000U * 200000U`: Тип данных `unsigned int`. Произведение 40 000 000 000 выходит за рамки допустимого максимума. Расчет остатка: 40000000000 % 4294967296 = **1410065408**.

### Задание 8 **(2)**

*Найдите результаты вычисления следующих выражений без использования компьютера
или калькулятора. Процесс вычислений должен быть отображен в отчете.*
* `(1000 & 100) << 10`
* `(1000 >> 4) & 15`
* `~1234 + 1234`
* `(1000 ^ 500) & 63`
* `(100 << 3) + (100 >> 3)`

**Ответ:**
* **`(1000 & 100) << 10`**: 
  Переведем числа в двоичную форму: 1000 = 1111101000_2, 100 = 1100100_2. Операция побитового И (&) оставляет 1000100_2, что равно 68. Битовый сдвиг влево на 10 позиций (`68 << 10`) равнозначен умножению на 1024: 68 * 1024 = **69632**.
* **`(1000 >> 4) & 15`**: 
  Сдвиг вправо на 4 бита эквивалентен делению на 16 нацело: 1000 / 16 = 62. В двоичном коде 62 = 111110_2. Число 15 в двоичной форме — это 1111_2. Побитовое И (&) отсекает все разряды, кроме четырех младших: получаем 1110_2 = **14**.
* **`~1234 + 1234`**: 
  Исходя из принципов построения дополнительного кода, операция побитового отрицания `~x` тождественна выражению `-x - 1`. Из этого получаем равенство: -1234 - 1 + 1234 = **-1**.
* **`(1000 ^ 500) & 63`**: 
  Константа 63 представляется как 111111_2 (6 младших бит). Наложение маски `& 63` выделяет только эти биты из результата. Выделим 6 младших бит у исходных чисел: у 1000 это 101000_2 (40), у 500 это 110100_2 (52). Выполняем для них операцию XOR (`^`): 101000 ^ 110100 = 011100_2 = **28**.
* **`(100 << 3) + (100 >> 3)`**: 
  Выражение `100 << 3` выполняет умножение на 8 и дает 800. Выражение `100 >> 3` выполняет целочисленное деление на 8 и дает 12 (остаток при этом теряется). Итоговая сумма: 800 + 12 = **812**.

###  Задание 9 **(2)**
*Напишите программу на языке С++ для умножения заданного целого числа на* $-1$. *В программе можно использовать только сложение и битовые
операции. Условия, циклы, библиотечные функции использовать нельзя.*

**Ответ:**
В рамках арифметики дополнительного кода инвертирование знака переменной реализуется как поразрядное отрицание всех бит числа с последующим добавлением единицы: -x = ~x + 1.

```cpp
#include <iostream>

int main() {
    int x;
    std::cin >> x;
    int y = ~x + 1;
    std::cout << y;
    return 0;
}
```
